01 / DATA

Datos + Dashboards

El motor que convierte tus fuentes en información accionable. Sin macros, sin planillas dispersas, sin "esto lo sabe solo Romina".

  • Conectores nativos: SAP, Oracle, Tango, Bejerman, REST, SQL
  • Saneamiento de duplicados y datos sucios con IA
  • Dashboards versionados, compartidos y exportables
  • Alertas por umbral y anomalías
02 / DOCS

DigitalDoc

OCR de última generación combinado con LLMs para extraer, clasificar y enrutar cualquier documento. Tu back office libre para tareas reales.

  • OCR para español y portugués · tablas y forms
  • Clasificación automática por tipo, urgencia, destino
  • Validación contra reglas fiscales y de negocio
  • Trazabilidad completa para auditorías

Workflows orquestados por agentes IA con políticas auditables. Cada paso queda registrado, cada excepción tiene dueño.

  • Editor visual de workflows sin código
  • Agentes con context window propio y herramientas
  • RBAC + SSO/SAML + auditoría
  • SLA monitoreado en tiempo real
Capacidades transversales

Lo que todos los módulos comparten.

ISO 27001 nativo

Cifrado at-rest y in-transit, gestión de claves, controles de acceso y logging completo. Auditables desde el panel.

Multi-tenant real

Aislamiento por tenant, cuotas, planes y branding propio. Pensado para gobiernos provinciales o grupos empresariales.

Observabilidad

Métricas, traces y logs estructurados. Alertas a Slack, Teams o tu canal preferido. Dashboards públicos para stakeholders.

API-first

REST + webhooks. SDKs en JavaScript, Python y .NET. Documentación OpenAPI generada y mantenida automáticamente.

Sin lock-in

Tus datos son tuyos. Exportación completa en formatos estándar. Documentación abierta del modelo de datos.

Self-hosted opcional

Cloud, on-premise o híbrido. Necesario para sector público y financiero con datos sensibles.

Agentes IA

El cerebro de la Suite.
Y vos lo controlás.

Los agentes orquestan tareas entre módulos: extraen datos, validan documentos, lanzan workflows. Cada acción queda auditada y vos definís sus límites.

Modelos curados, no caja negra

No te encadenamos a un proveedor de LLM. Cognition Suite enruta cada tarea al modelo correcto: el más rápido para clasificar, el más preciso para extraer, el más barato para responder.

  • Soporte para OpenAI, Anthropic, modelos open source on-prem
  • Routing automático por tipo de tarea + costo
  • Fallback transparente si un modelo falla
  • Logs por cada inferencia, con costo y tokens
